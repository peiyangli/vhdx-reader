# VHDX Reader Flutter client

Windows, Android, macOS and iOS/iPadOS clients share the Rust read-only VHDX reader. The iOS port builds for ARM64 devices and simulators; iPhone/iPad simulator integration tests pass. A development-signed Release build has been installed and launched on an iPhone SE (3rd generation), running iOS 27.2. Physical file access, media/audio and external-SSD interactions still require validation. See the [project README](../README.md) for build commands, tested platforms, and limitations.
